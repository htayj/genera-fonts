# Arch User Repository recipe

`genera-fonts-git/PKGBUILD` is a local/AUR VCS split-package recipe for the
co-installable `genera-fonts-latin-git` and `genera-fonts-symbols-git`
packages. Both outputs contain only Unicode BDF and OTB typefaces plus the
required manifests and notices; no VLOD, extracted source JSON, or raw font is
installed.
